# Elektro-Toolkit – Releases

Installer und Updates des **Elektro-Toolkits** (SIVAplan).

- **Herunterladen:** unter [Releases](../../releases/latest) die Datei `Elektro-Toolkit_<Version>_x64-setup.exe` ausführen.
- **Updates:** Das installierte Toolkit holt neue Versionen von hier und installiert sie nach Rückfrage selbst. In der App steht das unter Einstellungen → Info → „Nach Updates suchen“.

Dieses Repository enthält nur die fertigen, signierten Installer. Der Quellcode liegt nicht hier.
